# Niyam

A question-answering assistant for the Reserve Bank of India's payment regulations.

Ask a question about payment aggregators, prepaid instruments, or KYC rules.
Niyam answers only from the official RBI text, cites the exact clause, and
says so when the documents do not cover the question.

**Status:** in development.

This is not legal advice. Answers come from a dated snapshot of public RBI
documents and should be verified against the cited clause.
